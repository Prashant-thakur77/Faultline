# The crew

> GENERATED by `scripts/gen_agents_doc.py` from `backend/faultline/agent/crew.py` and `agent/phases.py`. Every incident is worked by these named, least-privilege roles. Each is deterministic code with its own tool whitelist enforced by the ToolBox (a call outside it is refused and recorded); only the lead investigator may use a language model, and the Gatekeeper never does: a model may propose, a read-only query decides. Each step is a record in FalkorDB: `(:Run)-[:HAS_TASK]->(:Task)-[:CLAIMED_BY]->(:Agent)`, the graph calls it made (`MADE`), and the hand-off order (`NEXT`); `Q-CREW-1` reads it back and the incident room's Crew board draws it. Crew records are records, not locks: execution is serialised by the Intent lease, and the gate runs in every run.

## The five investigators

The lead investigator dispatches them in parallel. Each claims its work item atomically (W-CLAIM-1, fenced by a claim epoch and renewed on every tool call) and returns a typed contract (`agent/contracts.py`), never prose; a contract that names an id the run never saw, or cites evidence another run produced, is rejected.

|---|---|
| topology | `causal_paths`, `impact_bound`, `upstream_scope` |
| telemetry | `metric_window` |

| change | `change_details`, `decision_check` |
| code | `diff_summary` |
