# Safety envelope: what the agent cannot do, and where that is enforced

Every row is enforced in code, not by prompt. The **Test** column points at the test that fails if the guarantee breaks.

| The agent cannot… | Enforced by | Where (file::function / template) | Test |
|---|---|---|---|
| write to the graph from a model-driven read | reads use `GRAPH.RO_QUERY` only; the model never holds a write connection | `graph/ro.py::RO.run`, `graph/client.py::ro_graph` | `tests/graph/test_ro_wrapper.py` |
| run arbitrary Cypher | templates first; text2cypher is guarded (masked text, no writes/comments/`GRAPH.*`, CALL allowlist, bounded paths, LIMIT ≤ 100), EXPLAIN-checked, RO_QUERY with a 3 s timeout | `graph/guard.py::guard`, `::check_plan`, `graph/ro.py::RO.run_guarded` | `tests/mcpserver/test_guard_blocks_writes.py` |
| read another tenant's graph | graph names are tenant-bound; RO wrapper and MCP binding refuse foreign graphs; per-tenant ACL user | `graph/tenant.py::graph_belongs_to`, `mcp_server/context.py`, `deploy/users.acl.template` | `tests/isolation/test_cross_tenant.py` |
| claim a cause without a causal path | gate G2: `algo.SPpaths` must return a path | `agent/gate.py::Gate.confirm`, `gate_path.cypher` | `tests/live/test_gate_s2.py`, `test_algo_load_bearing.py` |
| claim a cause that cannot carry the impact | gate G5: `algo.maxFlow` sufficiency (joint fixpoint across suspects) | `agent/gate.py::Gate.sweep/confirm`, `gate_flow.cypher` | `test_gate_s2.py::test_sweep_eliminates_fx…`; eval arm A3-noG5 |
| cite something it never read | G1: cited ids ⊆ ids SEEN by this run's tool calls (a read-only query decides) | `gate_grounding.cypher`; brain `cite_check.cypher` | `test_gate_s2.py::…ungrounded…`, `tests/brain/test_citation_guard.py` |
| invent an incident | no-incident needs N1 (measurements in band) **and** N2 (SSpaths negative proof; a full result means possibly truncated → refused) | `agent/gate.py::declare_no_incident`, `neg_proof.cypher` | S4D, S4S |
| act without a human | two-step approval: choose renders the exact action; approve must quote its plan hash; exclusive (moves to EXECUTE in the same query). On the public demo, only the visitor who started the run may approve (run token), and the approver must be an active person in the graph (identity not authenticated, see SECURITY.md) | `graph/writes.py::W_CHOOSE/W_APPROVE`, `actions/act.py::approve` | `tests/live/test_actions.py` (stale hash, re-choice, exclusivity) |
| bring back an option a human rejected | Reject (the human's "no") is bound to the exact action like approve: it must quote the current plan hash, needs a reason and an active approver, and in one query sets the action `status:'rejected'`, `enabled:false` with who/why/when and a stage event. `W_CHOOSE` requires `enabled`, `W_APPROVE` requires `status:'chosen'`, so a rejected option can never be re-chosen or approved; the incident stays `AWAITING_APPROVAL` for another choice. Nothing outside the graph is touched. Same guards as approve (run token, approver key on real GitHub). There is no `OVERRIDDEN_BY` edge: G8 never blocks, so no decision is overridden by a rejection | `graph/writes.py::W_REJECT`, `actions/act.py::reject`, `api.py::incident_reject` | `tests/live/test_reject_and_views.py::test_rejected_option_is_recorded_and_cannot_be_approved`, `tests/live/test_public_mode.py` |
| execute a stale or foreign plan | execute re-checks approved status, PENDING intent owned by this run, plan hash of the stored spec, and drift at GitHub main; refuses no-op changes | `actions/act.py::execute`, `::render` | `test_execute_refuses_a_stale_diff`, `…another_runs_intent`, `test_flag_already_off…` |
| touch anything but a fix branch | only `faultline/fix-*` branches can be created or merged | `actions/github.py::_check_branch` | `test_only_fix_branches_can_be_touched` |
| report success it cannot verify | 3-valued verify; UNKNOWN requires an explanation, goes to a human, and never writes success; a post-execute failure becomes UNKNOWN | `actions/act.py::verify`, `graph/writes.py::record_verdict/W_WB_2`, `api.py::_act_job` | S9 tests, `test_unknown_without_explanation…` |
| claim cross-system atomicity | intent → execute → reconcile by idempotency key; the reconciler attributes only its own merged fix PR | `actions/reconcile.py` | `test_reconciler_*` |
| learn a fix that didn't work | write-back of success only when APPLIED; failed attempts are `ATTEMPTED`, never `RESOLVED_BY`; derived runbooks come only from APPLIED actions | `graph/writes.py::W_WB_1/W_WB_2/W_MEM_CONSOLIDATE` | `test_rejected_fix_is_remembered…`, `tests/live/test_memory.py` |
| learn a failure link from a guess | a learned `PROPAGATES_TO` is only proposed after a rollback VERIFIED APPLIED on the world, only where the graph had no path and both ends were out of band; it exists only after a human approves the exact proposal, and the approval query re-checks APPLIED, an active approver and "still no path" in the same write | `memory/edges.py::propose`, `learn_gap.cypher`, `graph/writes.py::W_EDGE_APPROVE` | `tests/live/test_learned_edges.py` (wrong guess teaches nothing; re-checks), mutants `M-LEARN-UNVERIFIED`, `M-EDGE-APPROVE-RECHECK` |
| waive a decision silently | an override is two-step (plan hash), by an active person (approver key on the public demo), bound to the asserted value (a re-push with another value brings the violation back); only `intentional` takes the decision out of G8/preflight for that change | `api.py::decision_override`, `graph/writes.py::record_override`, `decision_contradiction.cypher`, `agent/rules.py::apply_override` | `tests/live/test_decision_override.py`, mutant `M-OVERRIDE-ANY` |
| touch a real graph from the playground | every change applies to a `GRAPH.COPY` twin of a clean room, through `writes.perturb_model`, which refuses any graph outside `eval_*` | `playground.py`, `graph/writes.py::perturb_model` | `tests/live/test_playground.py` |
| forget more than it showed | forget executes only with the token of the exact dry-run set; a receipt goes to the audit graph | `memory/forget.py`, `graph/writes.py::forget_doc` | `tests/memory/test_forget_receipt.py` |
| leak scenario answers into the product | truth files are read only by `evals/` and `tests/`; CI lint | `scripts/lint_no_leaks.py` | `tests/test_lint_no_leaks.py` |
| keep state outside FalkorDB | CI lint for other stores, numpy similarity, JSON state, hand-written graph algorithms | `scripts/lint_single_store.py` | `tests/test_lint_single_store.py` |
| hide a missing graph | `FAULTLINE_DISABLE_GRAPH` is checked on every call; the run fails closed; the UI shows a banner | `graph/ro.py`, `graph/client.py::engine` | eval arm A4 |
| write a record that breaks the evidence contract | FalkorDB refuses it in the same query: MANDATORY / UNIQUE constraints on nodes and edges (evidence provenance, a page's deadline, an approval's plan hash, `PROPAGATES_TO.cap`, every node's id, unique run and intent ids), on every golden, tenant, on-call and clean-room graph | `graph/constraints.py`, `graph/writes.py::ensure_constraints` | `tests/live/test_constraints.py` (one test per property, perturbation) |
| take the engine down with one query | per-query memory cap `QUERY_MEM_CAPACITY` (weights.yaml `engine.query_mem_capacity_mb`); the query fails, the engine stays up, the wrapper raises `GraphMemoryCapExceeded` (never 0 rows); covers any client, including the official MCP server | `scripts/configure_falkordb.py`, `graph/ro.py::classify` | `tests/live/test_mem_cap.py` |
| call an arbitrary UDF from text2cypher | function allow-list from the engine's own `dbms.functions()`: built-ins plus two vetted UDFs | `graph/guard.py::check_functions`, `engine_functions.cypher` | `tests/mcpserver/test_guard_functions.py` |
| send graph data out through the engine | prod FalkorDB is on an internal-only network with no route to the internet: no query can reach out | `deploy/docker-compose.prod.yml` | `tests/live/test_egress.py`, `tests/graph/test_engine_config.py` |
| count a write-back that is not on disk | `WAITAOF` on the writing connection before VERIFY counts the re-read; a timeout or error is UNKNOWN (escalated) | `graph/client.py::wait_aof`, `actions/act.py::write_back` | `tests/live/test_durable_writeback.py`, `tests/test_waitaof_units.py` |
| let a PR through a change freeze | preflight reads the tenant's freeze policies; FalkorDB evaluates the window on the wall clock and the verdict tightens to the policy's effect, with the policy cited | `preflight_freeze.cypher`, `preflight/score.py::apply_freeze` | `tests/preflight/test_freeze.py` |

The threat model for the public URL (who can do what as an anonymous visitor) is in [SECURITY.md](../SECURITY.md).
