# ADR-021: Catalog DB schema changes use online migrations

Schema changes on astronomy-db now go through an online migration tool that copies the table in the
background and swaps it in with a short metadata lock. Migrations may run at any hour, but must use the
online mode; plain `ALTER TABLE` against product tables is not allowed.

This supersedes ADR-009. The off-peak window did not stop lock contention, because night traffic still
queued behind long locks, and it pushed risky changes to hours when fewer people were around.
