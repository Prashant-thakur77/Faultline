# ADR-009: Catalog DB migrations run off-peak

Schema migrations against the product database take table locks that stall catalog reads. Until we have
a lock-free migration path, migrations on astronomy-db run only in the off-peak window (02:00 to 05:00 UTC)
and are announced in the catalog channel a day ahead.

This is a stopgap. Off-peak is not empty: storefront traffic from other regions still reaches the catalog
at night, so a long migration can still hurt.
